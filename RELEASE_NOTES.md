# DSA Video Generator 1.0.0

By Aikansh Katiyar. Third-party Codex plugin with portable local setup, a researched educational-video workflow, Two Sum and Knapsack examples, English system narration, measured scene timing, speech caching, portrait/landscape visuals, transcripts, and MP4 export.

Download `dsa-video-generator-1.0.0.zip` for the plugin package, or clone the repository for its local marketplace catalog and setup instructions. `two-sum-demo.mp4` was rendered by a fresh installation of this package.

Requires a local execution-capable Codex/ChatGPT Work host and Node.js 22+. Windows tested. No official directory approval: publisher identity verification is still required before upload. See README, TESTING, PRIVACY and THIRD_PARTY_NOTICES.
