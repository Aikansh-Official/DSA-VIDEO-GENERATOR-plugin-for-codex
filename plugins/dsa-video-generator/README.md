# DSA Video Generator

By Aikansh Katiyar. A skills-only plugin for Codex / ChatGPT Work with local execution. This directory is the plugin root; its `plugin.json` and `skills/` must stay together.

Ask the assistant to make an educational algorithm video. It follows [create-dsa-video](skills/create-dsa-video/SKILL.md), sets up a separate workspace, researches the problem, and renders narrated scenes. Two Sum and Knapsack are included. System voices require no speech API key.

Requires Node.js 22+, npm, local filesystem/shell access and an installed speech backend. Windows tested; other OS paths need verification. Ordinary chats without execution tools cannot run this package.

Repository, installation and support: https://github.com/Aikansh-Official/DSA-VIDEO-GENERATOR-plugin-for-codex
