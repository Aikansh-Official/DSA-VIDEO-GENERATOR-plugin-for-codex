# Privacy

Publisher: Aikansh Katiyar. This plugin has no publisher-operated server, account system, analytics, or telemetry. The bundled runtime writes lesson JSON, narration, cache, transcripts and MP4 files into the workspace selected by the user. It does not upload those files to the publisher.

The Codex/ChatGPT host processes prompts and tool results under its own terms and privacy settings. Source research visits the selected websites. Initial npm/browser installation and optional Piper/model installation contact package and model providers. System voices synthesize locally. Optional models carry their own licenses.

Users control their output files and can remove their generated workspace and uninstall the plugin. Public GitHub issues and release downloads follow GitHub's policies. Never send secrets or private recordings through support issues.
